# Dataset

El dataset utilizado en este estudio está compuesto por 1,200 imágenes de úlceras por presión (Grados I–IV), provenientes de cinco fuentes:

1. **Roboflow Universe** — https://universe.roboflow.com
2. **Kaggle** — https://www.kaggle.com/datasets/sinemgokoz/pressure-ulcers-stages
3. **figshare** — Chang C. W. (2021)
4. **FU Medical AI (PIID)** — https://doi.org/10.6084/m9.figshare.17206940.v1
5. **Dataset propio** — Recolectado en entorno hospitalario (no público por confidencialidad)

## Cómo obtener el dataset

Las imágenes de las fuentes 1–4 son de acceso público y pueden descargarse desde los enlaces indicados. El dataset compuesto (unificado y redimensionado a 224×224 píxeles) está disponible bajo solicitud al autor de correspondencia, indicando afiliación institucional y propósito de uso.
