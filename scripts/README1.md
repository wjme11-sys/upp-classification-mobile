# Scripts auxiliares

Scripts Python utilizados en el proyecto de clasificación de úlceras por presión (UPP).

## Archivos

### `preprocess_dataset.py`
Redimensiona y unifica las imágenes del dataset a 224×224 píxeles RGB.

**Uso:**
```bash
python preprocess_dataset.py --input "Dataset 3" --output "Dataset_3_resized"
